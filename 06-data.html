8  The data

Western States Survey (YouGov), fielded in 2020 and 2024 in Arizona, Colorado, Nevada, New Mexico, and Utah. R/00_build_data.R reads the two raw Stata files, harmonizes them, and writes the one analysis file distributed here. The raw files are not distributed; the CSV is.

wss_raw <- read_csv("data/wss_2020_2024.csv", show_col_types = FALSE)
dim(wss_raw)
#> [1] 7600   20
count(wss_raw, year)
#> # A tibble: 2 × 2
#>    year     n
#>   <dbl> <int>
#> 1  2020  3600
#> 2  2024  4000

8.1 What is in it

tibble(
  variable = names(wss_raw),
  type     = map_chr(wss_raw, ~ class(.x)[1]),
  n_miss   = map_int(wss_raw, ~ sum(is.na(.x))),
  distinct = map_int(wss_raw, n_distinct)
) |>
  knitr::kable()

The substantive columns, per the codebooks in codebooks/:

Variable Meaning
year, state survey year; AZ, CO, NV, NM, UT
weight survey weight (see below)
vote_choice Trump / Democrat / Other / Did not vote
vote_type whether the vote was reported or intended
trump_vote 1 Trump, 0 Biden/Harris, NA otherwise
age, female, race, latino demographics
educ (1–6), college, faminc (1–16) education and income
pid7, ideo5 party identification and ideology
auth1–auth4 child-rearing items; 1 = authoritarian response

The weight is already harmonized The 2020 file calls it weight and the 2024 file calls it weight_all; R/00_build_data.R renames the latter, so this file has a single weight column. An agent told “use the 2024 weight” will go looking for weight_all and not find it. This is exactly the kind of thing that belongs in AGENTS.md.

8.2 The outcome

trump_vote is defined only for two-party voters, which is where most of the missingness lives:

count(wss_raw, year, vote_choice) |>
  pivot_wider(names_from = year, values_from = n)
#> # A tibble: 5 × 3
#>   vote_choice  `2020` `2024`
#>   <chr>         <int>  <int>
#> 1 Democrat       1717   1936
#> 2 Did not vote     78    217
#> 3 Other           126    115
#> 4 Trump          1164   1678
#> 5 <NA>            515     54
wss_raw |>
  summarise(n_obs  = sum(!is.na(trump_vote)),
            n_miss = sum(is.na(trump_vote)),
            .by = year)
#> # A tibble: 2 × 3
#>    year n_obs n_miss
#>   <dbl> <int>  <int>
#> 1  2020  2881    719
#> 2  2024  3614    386

Reported and intended vote are not the same measurement, and the mix differs by year — something the analysis chapter has to take seriously:

count(wss_raw, year, vote_type) |>
  pivot_wider(names_from = year, values_from = n)
#> # A tibble: 3 × 3
#>   vote_type `2020` `2024`
#>   <chr>      <int>  <int>
#> 1 intended     636   1846
#> 2 reported    2449   2100
#> 3 <NA>         515     54

8.3 The authoritarianism items

Four forced-choice child-rearing pairs, each scored 1 for the authoritarian response:

wss_raw |>
  select(year, auth1:auth4) |>
  pivot_longer(auth1:auth4, names_to = "item") |>
  summarise(mean = mean(value, na.rm = TRUE),
            n_miss = sum(is.na(value)),
            .by = c(year, item)) |>
  pivot_wider(names_from = year, values_from = c(mean, n_miss)) |>
  knitr::kable(digits = 3)
item mean_2020 mean_2024 n_miss_2020 n_miss_2024
auth1 0.563 0.541 2 3
auth2 0.385 0.383 1 2
auth3 0.308 0.346 2 0
auth4 0.519 0.506 1 7
