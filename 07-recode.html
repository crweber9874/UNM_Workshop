9  The recode

One rule governs this chapter: every derived variable is created in R/01_recode.R, and nowhere else. Analysis scripts read the result; they never recode. The rule exists because an agent asked to “add a measure” will otherwise add it wherever it is currently looking, and two months later two scripts disagree about what party3 means.

9.1 The script

#> # Recode: data/wss_2020_2024.csv -> data/wss_clean.rds
#> library(tidyverse)
#> source("R/functions.R")
#> 
#> wss <- read_csv("data/wss_2020_2024.csv", show_col_types = FALSE)
#> stopifnot(all(c("auth1", "auth2", "auth3", "auth4", "pid7", "age") %in% names(wss)))
#> 
#> wss <- wss |>
#>   mutate(
#>     authoritarianism = auth_scale(pick(auth1:auth4)),
#>     auth_group = bin_auth(authoritarianism),
#>     age_group  = bin_age(age),
#>     party3     = pid_to_party3(pid7),
#>     race4      = fct_lump_n(race, 3, other_level = "Other") |> fct_infreq(),
#>     latino     = factor(latino, 0:1, c("Non-Latino", "Latino")),
#>     year       = factor(year)
#>   )
#> 
#> stopifnot(all(between(wss$authoritarianism, 0, 1), na.rm = TRUE))
#> write_rds(wss, "data/wss_clean.rds")

9.2 Running it

source("R/01_recode.R")
wss <- read_rds("data/wss_clean.rds")
dim(wss)
#> [1] 7600   25

It writes data/wss_clean.rds, which is git-ignored: the artifact is cheap to rebuild and the script is the thing worth versioning.

authoritarianism is the row mean of the four items, so it is bounded 0–1 by construction — and worth checking rather than assuming:

summary(wss$authoritarianism)
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max.    NA's 
#>  0.0000  0.0000  0.5000  0.4439  0.7500  1.0000       1

rowMeans(..., na.rm = TRUE) is a decision, not a default A respondent who answered one of four items gets a score built from that one item. That may be what you want, or it may not; either way it is an imputation rule, and it should be a deliberate choice rather than an argument an agent supplied because it suppresses NAs. A stricter version requires a minimum number of items:

auth_n = rowSums(!is.na(pick(auth1:auth4))),
authoritarianism = if_else(auth_n >= 3,
                           rowMeans(pick(auth1:auth4), na.rm = TRUE),
                           NA_real_)

9.4 How much did the recode cost us?

Derived variables inherit missingness from their inputs. Always know how much:

wss |>
  summarise(across(c(authoritarianism, auth_group, age_group, party3, latino),
                   ~ sum(is.na(.x)))) |>
  pivot_longer(everything(), names_to = "variable", values_to = "n_miss") |>
  mutate(pct = round(100 * n_miss / nrow(wss), 1)) |>
  knitr::kable()
variable n_miss pct
authoritarianism 1 0.0
auth_group 1 0.0
age_group 0 0.0
party3 309 4.1
latino 0 0.0

9.5 Asking an agent to extend it

A usable prompt is narrow, names its file, and asks for evidence:

Read AGENTS.md and R/01_recode.R. Add an income-tercile variable built from
faminc, weighted by `weight`. Add it to R/01_recode.R only. Then show me
the diff and a count() of the new variable.

Then check three things before you keep it: that the cutpoints are what you’d have chosen, that faminc really runs 1–16 with no missing-data codes hiding inside that range (the codebook, not range(), settles this), and that the row count of wss_clean.rds has not changed. The next chapter uses these variables; the one after makes the checks permanent.
